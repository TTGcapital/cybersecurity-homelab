# Evidence Guidelines

Evidence should prove results without exposing sensitive information.

Useful evidence includes Proxmox allocations, bridge topology, sanitised pfSense summaries, command output, expected access failures, successful validation after remediation, and snapshot names.

Never commit passwords, private keys, tokens, unsanitised pfSense backups, personal information, browser sessions or credentials. Private RFC1918 addresses may be documented as lab-only; public MAC addresses should be masked or omitted.
